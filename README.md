# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built using **React** and **Tailwind CSS**, designed to showcase projects, experience, and technical skills with a clean and aesthetic UI.

---

## 🚀 Features

- Modern dark theme with turquoise accent (#2acccc)
- Fully responsive design (mobile, tablet, desktop)
- Smooth navigation between sections
- Project showcase with hover effects
- Experience section with company logos
- Contact section with external profile links
- Clean, minimal, and professional UI

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **Version Control:** Git & GitHub
